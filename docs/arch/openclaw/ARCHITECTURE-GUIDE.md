## 一、项目概览

### 什么是 OpenClaw？

OpenClaw 是一个**运行在用户设备上的个人 AI 助手平台**，它具有以下核心特点：

| 特性 | 描述 |
|------|------|
| **多渠道支持** | 支持 Telegram、Discord、Slack、Signal、iMessage、WhatsApp、LINE 等消息平台 |
| **本地运行** | Gateway 运行在用户自己的设备上，数据不经过第三方服务器 |
| **多模型支持** | 支持 Anthropic、OpenAI、Google、OpenRouter、本地模型等 |
| **安全沙箱** | 代码执行在 Docker 沙箱中隔离 |
| **跨设备控制** | 支持通过 Nodes 控制 macOS/iOS/Android 设备 |
| **可扩展** | 支持插件、技能、钩子等扩展机制 |

### 核心理念

```
┌────────────────────────────────────────────────────────────────────────────┐
│                                                                            │
│   "Your AI, Your Rules, Your Data"                                        │
│                                                                            │
│   - Gateway 运行在你的设备上                                                │
│   - 消息和数据保留在本地                                                    │
│   - 你完全控制 AI 的行为和权限                                              │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 关键学习里程碑

| **M3: 理解 Runtime** | 能追踪一条消息从接收到 LLM 响应的完整流程 |

| **M5: 理解工具** | 能解释工具如何定义、注册、执行和返回结果 |
| **M6: 可以贡献** | 能添加新工具或修复 bug |

pnpm install

pnpm dev

### 8.2 调试技巧

```bash
# 启用详细日志
DEBUG=openclaw:* pnpm openclaw gateway run

# 查看沙箱容器
docker ps -a | grep openclaw-sandbox

# 进入沙箱容器
docker exec -it openclaw-sandbox-<slug> sh

# 查看会话日志
cat ~/.openclaw/agents/main/sessions/*.jsonl | tail -100

cat ~/.openclaw/config.yaml
```

## 总结

OpenClaw 是一个精心设计的个人AI助手平台，核心架构可以归纳为：

```
用户消息 → Gateway(路由+安全) → Runtime(LLM+工具) → 沙箱执行 → 结果返回
```

**学习建议：**

1. **先跑起来** - 按照 `docs/start/getting-started.md` 安装并运行
2. **理解架构** - 阅读本文档和 `docs/concepts/architecture.md`
3. **追踪代码** - 从 `runEmbeddedPiAgent()` 开始追踪一条消息的完整流程
4. **动手实践** - 尝试添加一个简单的工具或修改系统提示
5. **深入组件** - 按需深入学习感兴趣的组件

祝你学习愉快！🦞
