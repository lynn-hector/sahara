# 厦门两日周边游详细计划

## 📅 行程概览

**旅行主题**：海岛风光 + 文化体验 + 美食探索  
**最佳季节**：3-5月（春季）、9-11月（秋季）  
**适宜人群**：情侣、家庭、朋友结伴  
**行程特点**：合理安排，避免过度奔波，兼顾自然与人文

## 🚗 交通指南

### 到达厦门
1. **飞机**：厦门高崎国际机场
   - 机场大巴：20元/人，到市区约30分钟
   - 出租车：到市区约50-80元
   - 地铁：机场有地铁站

2. **高铁**：厦门站（市区）、厦门北站（岛外）
   - 厦门站：在市区，交通便利
   - 厦门北站：乘地铁1号线或BRT进岛

3. **自驾**：沈海高速、厦蓉高速可达

### 市内交通
1. **地铁**：目前有1、2、3号线
   - 1号线：连接厦门北站、中山路、集美学村
   - 票价：2-7元

2. **BRT快速公交**：
   - 专用高架道路，不堵车
   - 票价：1-4元

3. **公交车**：
   - 覆盖全面，票价1元
   - 支持支付宝、微信扫码

4. **出租车/网约车**：
   - 起步价：10元（3公里）
   - 网约车：滴滴、曹操出行等

5. **共享单车**：
   - 哈啰、美团等
   - 适合环岛路骑行

### 鼓浪屿船票
1. **购票方式**：
   - "厦门轮渡+"微信公众号
   - 支付宝生活号
   - 码头现场（可能售罄）

2. **航线**：
   - 日间：邮轮中心厦鼓码头→三丘田/内厝澳码头
   - 夜间：厦门轮渡码头→三丘田码头
   - 返程：任意时间，任意码头

3. **票价**：
   - 普通船：35元/人（往返）
   - 豪华船：50元/人（往返）
   - 市民票：8元/人（厦门市民）

### 土楼交通
1. **一日游团**：最方便，200-300元/人
2. **包车**：600-800元/天（5座车）
3. **自驾**：租车300-400元/天+油费
4. **公共交通**：
   - 动车：厦门→南靖，25元，30分钟
   - 南靖站→土楼：公交或拼车，30-50元

## ⚠️ 实用贴士

### 行前准备
1. **证件**：身份证（住宿、购票需要）
2. **衣物**：舒适鞋（步行多）、防晒衣、雨具
3. **防晒**：防晒霜、遮阳帽、太阳镜
4. **药品**：肠胃药、创可贴、防蚊液
5. **支付**：现金少量，主要用手机支付

### 避坑指南
1. **鼓浪屿**：
   - 不要买高价茶叶、珍珠
   - 不要相信"免费导游"
   - 岛上物价较高，可自带水

2. **土楼游**：
   - 选择正规旅行社
   - 不要购买"高价土楼照片"
   - 尊重当地居民，不随意进入民居

3. **海鲜**：
   - 问清价格再点单（按斤还是按份）
   - 选择明码标价的餐厅
   - 八市买海鲜可讲价

4. **交通**：
   - 不坐黑车
   - 出租车要求打表
   - 提前预订鼓浪屿船票

### 最佳拍照时间
1. **鼓浪屿**：早晨8-10点，人少光线好
2. **环岛路**：傍晚17-19点，日落美景
3. **土楼**：上午10-11点，光线适合建筑
4. **中山路**：晚上19-21点，灯光夜景

### 特殊人群建议
1. **带老人小孩**：
   - 选择集美学村方案，更轻松
   - 鼓浪屿可坐观光车（50元/人）
   - 注意防暑降温，多休息

2. **情侣游**：
   - 鼓浪屿住一晚，体验岛居生活
   - 环岛路骑行，浪漫海边
